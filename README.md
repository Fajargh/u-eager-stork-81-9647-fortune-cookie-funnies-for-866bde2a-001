One original fortune cookie message for a software engineer — a single line of at most 120 characters, fresh enough that no mug, sticker, or conference slide has ever carried it. The program writes the line to `/output/entry.txt`.

> Your flaky test will pass in CI today, then fail the second your manager watches the demo.

## Run it

```bash
python3 main.py
cat /output/entry.txt
```
